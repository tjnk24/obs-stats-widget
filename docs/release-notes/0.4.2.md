- New StreamoScope icon: on the installer, in its window, in Windows Settings → Apps and next to the Lua bridge description in OBS Tools → Scripts.
- The installer no longer removes obs-stats-widget 0.1.0–0.2.0. If it is still installed, uninstall it in Windows Settings → Apps before installing StreamoScope.
