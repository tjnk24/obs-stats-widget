First public release.

- A card for the main stream and for every plugin output that streams (obs-multi-rtmp and others): live bitrate with a graph, dropped frames, network congestion and a status tag.
- Platform detection: YouTube, Twitch, Kick, VK Video Live, VK Video, Rutube, Telegram, Facebook and Trovo.
- OBS card: FPS, frame time, skipped and missed frames, CPU and memory; GPU load and system memory through the bridge script.
- Installer for Windows: adds the dock and the bridge script to OBS and turns on the WebSocket server, no administrator rights needed.
- Updates: the dock checks GitHub for new versions and installs them in one click; downloads are checked against the release signature.
- Hints when something is missing: the bridge script is not loaded in the scene collection, the WebSocket server is off, a scene collection switch is in progress.
- Interface in English, Russian, Spanish, German and Brazilian Portuguese, following the OBS language.
- Copy diagnostics and error reports from the dock for bug reports.

Первый публичный выпуск.

- Карточка основного стрима и каждого выхода плагинов, который стримит (obs-multi-rtmp и другие): битрейт с графиком, пропущенные кадры, перегрузка сети и статус.
- Определение площадки: YouTube, Twitch, Kick, VK Video Live, VK Видео, Rutube, Telegram, Facebook и Trovo.
- Карточка OBS: FPS, время кадра, пропущенные кадры, процессор и память; загрузка видеокарты и память системы через скрипт-мост.
- Установщик для Windows: добавляет панель и скрипт-мост в OBS и включает сервер WebSocket, права администратора не нужны.
- Обновления: панель проверяет новые версии на GitHub и ставит их в один клик; скачанное сверяется с подписью выпуска.
- Подсказки, когда чего-то не хватает: скрипт-мост не подключён в коллекции сцен, выключен сервер WebSocket, OBS переключает коллекцию сцен.
- Интерфейс на английском, русском, испанском, немецком и бразильском португальском, по языку OBS.
- Диагностика и отчёты об ошибках копируются прямо из панели.
