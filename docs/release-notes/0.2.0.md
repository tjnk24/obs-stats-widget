- Settings → Updates: after "Check for updates" finds a new version, an Update button appears right next to it (or Download manually when the update cannot be installed automatically). Pressing it scrolls the dock up to the install progress.
- The README now has screenshots, explains the Windows SmartScreen warning and how to check a download; bug reports and ideas have issue forms.

- Настройки → Обновления: если «Проверить обновления» нашла новую версию, рядом появляется кнопка «Обновить» (или «Скачать вручную», когда поставить автоматически нельзя). После нажатия панель прокручивается наверх, к ходу установки.
