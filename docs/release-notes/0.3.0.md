obs-stats-widget is now **StreamoScope**, by Froghead Works.

- **Coming from 0.1.0–0.2.0:** your dock can't update to this version by itself, because everything got a new name. Close OBS and run `streamoscope-setup-0.3.0.exe` once: it removes obs-stats-widget first, then installs StreamoScope. Your saved WebSocket password and settings come along.
- The dock in OBS is now Docks → StreamoScope, the bridge script is `streamoscope-bridge.lua`, and the program lives in `%LOCALAPPDATA%\Programs\streamoscope`. The repository moved to `tjnk24/streamoscope`; old links keep working.
- From here on, updates from the dock work as before.
